# Верстак идей — публикация GitHub Pages

Публичная версия доски вдохновения: DIY, реставрация, инструменты и Белгород. Содержит только уже опубликованные карточки, превью и интерфейс. Работает статически без GPT и без обращений к исходному серверу из браузера.

Публикация выполняется штатно из ветки main. GitHub Actions сейчас заблокирован GitHub из-за состояния биллинга аккаунта; workflow отключён. Серверная подборка продолжает обновляться каждые шесть часов. Локальный сопровождающий Codex публикует её снимок через существующий heartbeat, когда наступил срок; это требует работающего компьютера и Codex. При недоступности источника сохраняется комплектная подборка с видимой датой проверки. Скрипт копирования: .github/scripts/sync.py. После восстановления Actions можно вернуть workflow-публикацию.

Избранное сохраняется в браузере отдельно для каждого адреса сайта. При переходе со старого адреса прежнее избранное автоматически не переносится.

Раздел Белгорода различает каталоги продавцов и поиски Авито; поисковые ссылки не являются проверенными активными объявлениями.
